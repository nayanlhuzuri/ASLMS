Design system

One rulebook every screen follows, so sizes, spacing and colours stay uniform across the portal.

Principles

How each screen keeps information under control.

Summary firstEach page opens on the few facts that matter; details open on demand in a side panel or a tab.
One main actionOne blue primary button per screen or panel; everything else is secondary.
Same sizes everywhereEvery gap on an 8-point grid; one height for every button and field (36 px).
Everything lines upBadges, dates and icons that lead a row sit in a fixed-width column, so the text after them always starts at the same place.
Colour means somethingRed = urgent or overdue, amber = due soon, green = done, blue = action. Never decoration.
Calm motionShort (0.15–0.3 s) fades and slides; switched off when the computer asks for reduced motion.
Ready for other languagesAll text from one file; layouts leave room for longer words; dates and numbers formatted per language.

A neutral base with a single blue accent; status colours with fixed meanings.
