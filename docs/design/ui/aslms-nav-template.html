Label Style

One rule for every label, so menus, tabs, buttons and headings read the same everywhere.

The Rule

  • Labels use Title Case: each word starts with a capital letter and the rest is small.
  • Short joining words stay small unless they come first or last: a, an, the, and, or, of, by, to, in, on, for, at, with. So “Sent by Me”, but “Working On”.
  • Acronyms stay in capitals: ASLMS, CNR, NAPIX, PDF.
  • User type names are always written in full, never shortened: Department Administrator, not Dept admin.
  • It applies to menu entries, tabs, buttons, card titles, column headers, field labels and section headings.
  • Sentences keep normal sentence case: hints, notices, descriptions and error messages.

Filter Layouts

Three ways to lay out the Cause List filters so they use the full width instead of one narrow column. Each works with the sample list below it.

Layout A · One-Line Toolbar

Labels: placeholders, with the 3-character hint as a tooltip. One row at full width; it wraps to two rows when narrower and stacks on phones.

Suits daily users who mostly change the date and search · Pros one line, nothing used daily is hidden, familiar · Cons no visible labels, so new users lean on placeholders and tooltips.

Layout B · Header Card with Two Zones

Labels: small labels above the boxes. The date is the hero on the left; the other filters sit in a tidy grid on the right.

Suits officers who come to the Cause List for one day at a time and want the date unmissable · Pros clear labels, calm and balanced, a summary at a glance · Cons taller than A, so the list starts lower on the page.

Layout C · Sticky Filter Bar + Side Filters

Labels: placeholders in the bar; small labels above the boxes in the side panel. The bar stays in view while you scroll; the panel collapses, and on phones it opens from a Filters button.
