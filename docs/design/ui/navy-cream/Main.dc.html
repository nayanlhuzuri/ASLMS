Where Orange Goes, and Where It Never Goes

Orange
The one main button on a page
The selected menu item and tab marker
Counts that need action (unread alerts, files with me)
The keyboard focus ring
Never orange
Body text and large backgrounds
Urgent, due soon or done (status colours keep those)
White text on orange (fails contrast)
More than one orange button per page

Status Colours Stay Apart From Orange

Today Overdue In 3 Days Confirmed Disposed
Urgent red is dark and solid; orange is bright. Due soon moves from amber to a darker ochre, so it is not mistaken for orange.
Contrast (AA needs 4.5): ink on cream 14.2 · navy on orange 6.7 · deep orange on cream 4.9 · grey text on cream 5.2 · white on orange 2.5, so never used
